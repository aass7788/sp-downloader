```
│                 │  JSON: CDN 直链列表     └───────────────────────┘
│                 │
│                 │    GET CDN 直链         ┌───────────────────────┐
│                 │ ────────────────────▶ │  TikTok / 抖音 CDN     │
│                 │ ◀──────────────────── │  (视频文件)            │
│                 │  视频文件流             └───────────────────────┘
└─────────────────┘
```
